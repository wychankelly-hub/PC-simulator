📘 系統硬體單元功能說明 (點擊卡片展開細節)
🧠 CPU (中央處理器) ▼
核心功能： 電腦的大腦，負責執行作業系統與軟體的所有指令、算術與邏輯運算。
安裝說明： 必須精確對齊主機板上的 LGA 或 AM5 插座防呆缺口，並鎖緊壓桿。
⚡ DDR5 / SDRAM (主記憶體) ▼
核心功能： 隨機存取記憶體，為 CPU 提供高速的臨時資料讀寫通道。關機後資料會自動消失。
安裝說明： 對準 DIMM 插槽中央的防呆凸起，雙手同時用力向下壓直至兩端扣具自動扣上。
🎮 PCIe GPU (獨立顯示卡) ▼
核心功能： 專門處理 3D 圖像渲染、影片剪輯與 AI 深度學習算力。
安裝說明： 插入主機板第一條金屬加固的 PCIe x16 插槽，並確認尾端安全鎖扣已彈回鎖定。
🚀 M.2 NVMe SSD (固態硬碟) ▼
核心功能： 採用 PCIe 通道的高速非揮發性儲存設備，用於安裝 OS 與長期存放個人檔案。
安裝說明： 以 30 度角斜向插入 M.2 插槽，向下壓平後鎖上螺絲或快拆扣具。
❄️ CPU 散熱器 (Heatsink / Fan) ▼
核心功能： 將 CPU 運作時產生的高溫快速導出，防止系統過熱降頻或當機。
安裝說明： 安裝前必須在 CPU 表面塗抹適量散熱膏，並固定於 CPU 正上方。
🔌 24-Pin ATX 主機板電源插座 ▼
核心功能： 將電源供應器 (PSU) 的電力輸送至主機板，為晶片組、記憶體及周邊供電。
安裝說明： 認準卡扣方向，垂直插入直至聽見卡嗒鎖定聲。
